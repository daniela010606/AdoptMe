# AdoptMe
Cat adoption website
My website is dedicated to the adoption of kittens that have been rescued from the streets. On this website the user finds information about each kitten, its history, and photos so each person can choose the one they like the most.
I used pastel colors (pink, purple, lavender, and light blue) I also used Google Fonts for the fonts, I selected Cambay and Delius Unicase, and I imported them into my HTML using a link in the head section. I also used flexbox to organize the menu, also CSS Grid to organize the pictures in the Gallery and Media queries of 601px and 768px. For smaller screens, the gallery page has one column but for bigger screens it has two.
I also used semantic HTML (header, nav, main, section, footer). Alt text for images, labels, and HTML validation for the Contact Us page. Overall, this project helped me improve my HTML and CSS coding skills, it also helped me learn new elements and features in HTML and CSS which made me enjoy the process. I also learned how to organize different pages while keeping the same design and using the same CSS file and all these new features and elements made my website easier to navigate and helped users find the information they need.
